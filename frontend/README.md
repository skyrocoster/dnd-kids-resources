# Frontend

React and Vite client; frontend commands are defined in `package.json`.

- `src/` — application, tests, Storybook stories, and theme token tools
- `src/tools/` — theme token generators and the known-test-failure checker
- `.storybook/` — Storybook configuration

Run the palette tests from `frontend/` with:

```powershell
npm run test -- src/__tests__/derive-kid-palette.test.mjs
```

Theme tokens are generated by the Node tools in `src/tools/`.
