# Monster stat-block catalogue: repository migration map

> **Handoff status:** evidence-backed reference for a possible later, separately approved migration. This is documentation only. The seven catalogue artifacts are standalone HTML/design references, not a production component specification, signed-off Storybook direction, data/API contract, or approval to integrate them. Reading or selecting an HTML reference does not approve its styling or layout for the app. See `experiments/monster-stat-block-catalogue/dnd-concept-breakdown.md:3-5,19,60,62-64`.

## How to use this map

- **Observed** means the cited experiment, current source, schema, seed, or test says it. It is not a new product decision.
- **Candidate / option** means a possible future seam or treatment to take into a production-backed Storybook review and, later, an approved integration Plan. It is not a component API or acceptance decision.
- **Unknown / needs approval** means the inspected evidence does not settle the behavior. Keep the current behavior or data; do not fill the gap with a prototype assumption.
- Paths and line ranges are repository-root-relative. Source line references describe the inspected repository snapshot and should be refreshed narrowly if those files move before a later Plan.
- For compact tables, these unique basenames are path abbreviations: `MonsterStatBlock.tsx`, `MonsterStatBlock.css`, `monsterModel.ts`, `MonsterBrowserPage.tsx`, `MonsterBrowserPage.css`, `BrowserLayout.css`, `Monsters.stories.tsx`, `Card.tsx`, `BrowserLayout.tsx`, `SearchList.tsx`, `PreviewCard.tsx`, `theme.css`, `viewports.ts`, `preview.tsx`, `types.gen.ts`, `creatures.py`, `NPCStatCard.tsx`, `NPCStatCard.css`, `npcModel.ts`, `npcPull.ts`, `PullFromMonsterDialog.tsx`, `PlayerCombatSummary.tsx`, `PlayerCombatSummary.css`, `playerModel.ts`, `MonsterStatBlock.test.tsx`, `MonsterBrowserPage.test.tsx`, `NPCStatCard.test.tsx`, `PullFromMonsterDialog.test.tsx`, and `PlayerCombatSummary.test.tsx` refer to the correspondingly named files under the current app paths identified in the architecture/consumer tables below. `dnd-concept-breakdown.md`, `unified-monster-stat-block.html`, `identity.html`, `vitals.html`, `ability-scores.html`, `proficiencies.html`, and `detail-regions.html` refer to the seven artifacts under `experiments/monster-stat-block-catalogue/`; `seed_monsters.json` refers to `data/seeds/seed_monsters.json`.
