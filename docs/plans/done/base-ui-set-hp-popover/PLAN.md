## Outcome

Use the existing shared Popover for the monster Set HP panel while retaining its current compact presentation, numeric behavior, focus behavior, and Apply/Enter/retoggle-only close paths.

## Scope

- **Included:** Characterize and migrate only the Set HP panel in `CombatantCard`. Preserve its CSS presentation, autofocus, current focus behavior, and `onSetHp` contract.
- **Expected areas:** `frontend/src/features/encounters/CombatantCard.tsx`, `frontend/src/features/encounters/CombatantCard.css`, and `frontend/src/features/encounters/__tests__/EncounterRunnerPage.test.tsx`. Reuse `frontend/src/components/Popover.tsx` as-is; it is not an edit target.
- **Excluded:** Other CombatantCard controls, encounter rules or state ownership, shared Popover/API changes, field or numeric adapters, dependencies, other overlays, visual redesign, backend changes, and unrelated worktree changes.
