# Candidate Ideas Bank

This is a lightweight store for candidate ideas that emerge from table-testing evidence.
Ideas have an independent lifecycle: they may be captured, clarified, or discarded without
changing the source table-test record or creating an implementation Plan.

Each idea must link back to the table-test record that prompted it. Keep the evidence in the
record; use an idea card only to capture the candidate direction and the questions that remain.
Ideas are separate from both table-test records and implementation Plans. A candidate becomes
Plan work only through the normal planning process, not by appearing in this bank.

Copy [`_example/idea-card.md`](_example/idea-card.md) when capturing a candidate. This directory
is intentionally not a generated index or queue.
