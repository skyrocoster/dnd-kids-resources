# Table-test template

`session-template.md` is the blank form for a table test — a real session, run with the real
operators, on the real device.

To start a new record, copy the template to `docs/table-tests/YYYY-MM-DD-<slug>.md`, where the date
is the date the session is played and the slug names the plan and stage it serves. Fill **Setup**,
**Watching for**, and the header before the session; leave **Observed**, **Asked afterwards**, and
**Verdict** empty for the human who runs it.

This folder is a template only. It holds no session data and is never read for facts about the
product. Files here are deliberately excluded from the record index.
