# Table-test template

`session-template.md` is the blank form for a table test — a real session, run with the real
operators, on the real device.

To start a new independent record, copy the template to
`docs/table-tests/YYYY-MM-DD-<slug>.md`, where the date is the date the session is played and the
slug briefly identifies it. Fill the header and one to five focused question blocks before the
session. For each question, record the expectation, confirmation or challenge signal, actual
outcome, interpretation, and possible ideas. Preserve raw evidence as written; ideas are not
implementation plans.

Use `draft` while preparing the record, `recorded` once the session evidence is captured, and
`reviewed` once the interpretations have been checked. The template is intentionally compact and
does not require a Plan, Stage, standing questions, extra notes, or Actions section. Add optional
links only when they are useful, and never edit real session records from this folder.

This folder is a template only. It holds no session data and is never read for facts about the
product. Files here are deliberately excluded from the record index.
